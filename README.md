# AI 기초 — 헷갈리는 용어부터

사내 임직원 대상 AI 기초 강의자료입니다. ChatGPT를 써본 사람을 전제로, 헷갈리는 용어 정리부터 업무 적용까지 60분 분량으로 구성했습니다.

## 구성

| 파일 | 내용 |
|------|------|
| `index.html` | **반응형 프레젠테이션** (33장). 강의장에서 띄우는 용도 |
| `handbook.html` | **교재** — 개념 핵심 · 업무 핵심 · 전체 교재 3개 탭. 배포·복습용 |

## 프레젠테이션 조작

| 동작 | 방법 |
|------|------|
| 다음 / 이전 | `→` `Space` / `←` · 화면 하단 `‹` `›` · 모바일 좌우 스와이프 |
| 전체 목차 | `O` 또는 `☰` |
| 전체 화면 | `F` 또는 `⛶` |
| 라이트·다크 | `T` 또는 `◐` |
| 처음 / 끝 | `Home` / `End` |
| PDF로 저장 | 브라우저 인쇄 → PDF (장별로 한 페이지씩 나뉩니다) |

주소 끝에 `#12`처럼 장 번호를 붙이면 그 장으로 바로 열립니다.

## 강의 진행 (60분)

| 시간 | 내용 |
|------|------|
| 0~5분 | 도입 — "쓰긴 쓰는데 헷갈리는 말" 받아적기 |
| 5~28분 | 개념 핵심 — 세 층 · 원리 3줄 · 용어 8개 · 헷갈리는 짝 4개 |
| 28~40분 | 잘 시키는 법 + 지시문 고쳐 쓰기 실습 8분 |
| 40~52분 | 업무 핵심 — 1·2·3단계로 할 수 있는 일 |
| 52~57분 | 지켜야 할 것 — 보안 · 검수 · 비용 |
| 57~60분 | Q&A · 마무리 |

따로 내주는 과제는 없습니다. 실습은 모두 강의 시간 안에서 끝냅니다.

시간이 모자랄 때 줄이는 순서는 ① 헷갈리는 짝 4개 중 2개 ② 용어 사전 통독 ③ 도구 선택표입니다. **원리 3줄과 보안은 줄이지 않습니다.**
