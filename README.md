# AI 기초 — 헷갈리는 용어부터

사내 임직원 대상 AI 기초 강의자료입니다. **ChatGPT와 Claude를 함께** 다루고, 60분 중 절반을 **업무 문서 만들기 실습**에 씁니다.

## 폴더 구조

```
ai-basics/
├── docs/          ← 강의자료 (GitHub Pages가 이 폴더를 그대로 배포)
│   ├── index.html      반응형 프레젠테이션 28장
│   └── handbook.html   교재 (개념 핵심 · 업무 핵심 · 전체 교재 3탭)
├── src/           ← 원고 · 소스
│   └── 260901_AI기초강의자료_마건우_v2.0.md   원고 정본
└── README.md
```

| 경로 | 역할 | 주소 |
|------|------|------|
| `docs/index.html` | 강의장에서 띄우는 프레젠테이션 | https://gwma-manager.github.io/ai-basics/ |
| `docs/handbook.html` | 배포·복습용 교재 | https://gwma-manager.github.io/ai-basics/handbook.html |
| `src/*.md` | **원고 정본.** 내용은 여기서 먼저 고칩니다 | — |

**수정 순서** — `src/` 원고 수정 → `docs/` 반영 → commit·push → 1~2분 뒤 사이트 자동 갱신.

> PDF는 레포에 올리지 않습니다. 필요하면 프레젠테이션에서 브라우저 인쇄 → PDF로 그때 뽑아 씁니다. (`.gitignore`에 `*.pdf` 등록)

## 프레젠테이션 조작

| 동작 | 방법 |
|------|------|
| 다음 / 이전 | `→` `Space` / `←` · 화면 하단 `‹` `›` · 모바일 좌우 스와이프 |
| 전체 목차 | `O` 또는 `☰` |
| 전체 화면 | `F` 또는 `⛶` |
| 라이트·다크 | `T` 또는 `◐` |
| 처음 / 끝 | `Home` / `End` |
| PDF로 저장 | 브라우저 인쇄 → PDF (장별로 한 페이지씩 나뉩니다) |

주소 끝에 `#12`처럼 장 번호를 붙이면 그 장으로 바로 열립니다.

## 강의 진행 (60분)

| 시간 | 내용 |
|------|------|
| 0~5분 | 도입 — 헷갈리는 말 받아적기, 다음 주에 쓸 문서 정하기 |
| 5~20분 | 기초 개념 — 엔진과 서비스 / ChatGPT·Claude 비교 / 모델 등급 / 원리 세 줄 |
| 20~30분 | 잘 시키는 법 — who·why·what·how, 바꿔 쓰기 |
| 30~52분 | **실습** — 업무 문서 한 건을 4단계로 완성 |
| 52~57분 | 지켜야 할 것(보안·검수) · 다음 단계 안내 |
| 57~60분 | Q&A |

### 실습 4단계

재료 붙이기 → 뼈대 잡기 → 살 붙이기 → 검토시키기.
한 번에 다 시키지 않고 단계마다 확인하고 넘어갑니다. 각 단계의 지시문 예시가 슬라이드에 그대로 들어 있습니다.

만들 문서는 회의록 정리본 / 안내·제안 메일 / 주간 업무 보고서 중에서 고르되, **다음 주에 실제로 써야 할 문서**면 가장 좋습니다.

따로 내주는 과제는 없습니다.

스킬·커넥터·RAG·임베딩 같은 개념은 기초 강의에서 빼고, 마지막에 **"다음 단계에 이런 게 있습니다" 한 장**으로만 다룹니다. 자세한 내용은 `handbook.html`에 있습니다.
