개념 1

AI를 세 층으로 봅니다

"AI"라는 한 단어가 서로 다른 세 가지를 가리킵니다. 이걸 나누면 대부분의 혼란이 정리됩니다.

엔진LLM
실제로 생각하고 답을 만드는 부품입니다. GPT · Claude · Gemini가 각기 다른 회사의 엔진입니다.
서비스Service
그 엔진을 감싼 완성품 앱·사이트입니다. ChatGPT · claude.ai가 서비스입니다.
모델Model
같은 엔진 안의 성능 등급입니다. 빠르고 싼 등급부터 똑똑하고 비싼 등급까지 나뉩니다.

자동차로 보면 — 엔진은 눈에 안 보이지만 힘을 냅니다. 자동차는 우리가 타는 완성차입니다. 같은 엔진이라도 어떤 차에 얹느냐에 따라 타는 경험이 달라집니다.

그래서 "GPT 써봤어"는 정확히는 "ChatGPT라는 서비스를 통해 GPT 엔진을 썼다"는 뜻입니다. 도구를 고를 때 엔진 성능과 서비스 편의성은 따로 봐야 합니다.

1-2토큰 · 컨텍스트 · 세션 · 리밋

넷은 하나로 이어진 이야기입니다. "AI가 한 번에 볼 수 있는 양"을 둘러싼 말들입니다.

토큰은 AI가 글을 처리하는 가장 작은 조각입니다. 영어는 대략 1토큰이 4글자, 한국어는 조사·어미 때문에 더 잘게 쪼개져 같은 내용에 토큰을 1.5~2배 씁니다. 내가 넣는 것과 AI가 답하는 것 양쪽 다 토큰이고, 첨부한 PDF·프로젝트 지식·시스템 지시문까지 전부 포함됩니다.

컨텍스트 윈도우는 AI가 한 번 답할 때 동시에 볼 수 있는 토큰 총량입니다. AI의 작업 기억이라고 보면 됩니다.

가장 흔한 오해

AI는 대화를 기억하지 않습니다.

답할 때마다 지금까지의 전체 대화를 처음부터 다시 읽습니다. 그래서 대화가 길어질수록 한 번 답하는 비용이 계속 커집니다. 100번째 메시지는 첫 번째 메시지보다 훨씬 비쌉니다.

대화 세션

채팅 방 하나. 여기에 길이 한계가 걸립니다. 새 대화를 열면 기억이 초기화됩니다.

뜻 2
사용량 세션

사용량을 세는 시간 창. 첫 메시지 시점부터 약 5시간 단위로 굴러갑니다. 자정 기준이 아닙니다.

구분사용량 리밋길이 리밋
무엇을 제한일정 기간 동안 얼마나 많이한 대화가 얼마나 길게
범위계정 전체개별 대화 하나
걸렸을 때리셋 대기 · 플랜 상향새 대화 시작

같은 계정이면 모든 제품의 사용량이 합산됩니다. 아침에 한 도구에서 많이 쓰면 오후 여유분이 줄어듭니다.

사용량 절약 5가지

  1. 주제가 바뀌면 새 대화로. 효과가 가장 큽니다.
  2. 반복해서 쓰는 자료는 프로젝트 기능에 넣습니다.
  3. 프로젝트 지시문은 짧게. 작업별 지시는 채팅에서 합니다.
  4. 안 쓰는 파일·커넥터·웹 검색은 꺼둡니다.
  5. 쉬운 일은 노력도를 낮춥니다.

1-3프롬프트 · 컨텍스트 · 하네스

이 셋은 대체 관계가 아니라 포함 관계입니다. 양파 껍질처럼 뒤가 앞을 감쌉니다.

층무엇을 정하나단위상담 챗봇에 대입하면
프롬프트무엇을 말하나메시지챗봇에게 준 답변 규칙
컨텍스트무엇을 보여주나세션챗봇이 참고할 회사 문서
하네스어떻게 실행하나시스템문서를 검색해 답변에 끼워 넣는 구조 전체

답이 마음에 안 들 때 어디를 고칠지가 갈립니다. 말투가 문제면 프롬프트, 내용이 틀리면 컨텍스트(자료), 매번 같은 실수가 반복되면 하네스(구조)를 봅니다.

1-4챗봇 · 에이전트

챗봇은 물으면 한 번 답하고 끝납니다. 에이전트는 스스로 일을 돌립니다.

계획 → 실행 → 자기검토 → 다음 결정 ↑ │ └────────────────────────────┘

이 네 단계를 혼자 돌고 또 돌면서 일을 끝까지 해냅니다. 이것을 에이전트 루프라고 합니다.

서브에이전트는 대표 AI가 조수 AI 여러 개를 만들어 동시에 일을 시키는 방식입니다. "경쟁사 5곳을 조사해줘"를 한 AI가 순서대로 하면 뒤로 갈수록 앞 내용이 작업 기억에 쌓여 품질이 떨어집니다. 조수 5명에게 하나씩 맡기면 각자 빈 노트로 시작해 동시에 조사합니다. 더 빠르고, 각자 하나에만 집중하니 더 정확합니다.

1-5할루시네이션 · RAG

할루시네이션(환각) — AI는 "정답을 아는" 게 아니라 그럴듯한 다음 단어를 예측하는 방식으로 동작합니다. 그래서 틀린 내용을 자신 있게 말하기도 합니다.

RAG — 아무 말이나 지어내지 않도록, 먼저 정해진 자료를 찾아보고 그 안에서 답하게 하는 방식입니다.

시험을 볼 때 머릿속 기억으로만 푸는 게 아니라, 교과서를 펴놓고 찾아서 답하는 것입니다.

RAG가 실제로 도는 순서

  1. 준비 — 회사 문서를 잘게 쪼개 의미를 담은 숫자로 바꿔 저장합니다.
  2. 질문 — 사용자가 물으면 그 질문도 같은 방식으로 숫자로 바꿉니다.
  3. 검색 — 숫자가 가까운 = 의미가 비슷한 문서를 찾습니다.
  4. 답변 — 찾은 문서를 근거로 답합니다. 없으면 "모른다"고 답하게 규칙을 겁니다.
여기서 나오는 말쉬운 뜻
임베딩문장을 의미가 담긴 숫자 목록으로 바꾸는 것. 모든 문장에 의미 좌표를 찍는 겁니다
벡터그 숫자 목록
청크긴 문서를 검색하기 좋게 자른 작은 조각
벡터DB그 숫자들을 저장하고 가까운 것을 찾아주는 창고

키워드 검색은 "환불"로 물으면 "반품 규정" 문서를 못 찾습니다. 벡터 검색은 단어가 달라도 뜻이 가까우면 찾아냅니다.

1-6스킬 · 커넥터

가장 많이 헷갈리는 짝입니다. 하나는 방법, 하나는 권한입니다.

내부 지식
스킬

어떻게 할지 아는 매뉴얼. AI 내부에 저장된 지침 묶음입니다. 문맥을 보고 스스로 켭니다.

외부 통로
커넥터

무엇에 접근할지 여는 문. 메일·문서·메신저 같은 외부 서비스로 연결합니다. 설정에서 승인해야 켜집니다.

헷갈리기 쉬운 전제

스킬은 방법만 담습니다. 권한은 주지 않습니다. 메일 정리 스킬이 있어도 메일 커넥터가 연결돼 있지 않으면 동작하지 않습니다.

스킬이 태어나는 방식

거창하지 않습니다. 평소 반복하던 작업을 그대로 굳힌 것입니다. 메일과 일정을 분석해 "정리해줘"라고 시켰고, 결과가 쓸 만하자 "이 흐름을 다음에도 부를 수 있게 스킬로 만들어줘"라고 지시했습니다. 그 과정에서 설명서 파일 하나가 생겼고, 그게 스킬입니다. 즉 "한 번 잘 시킨 작업을 재사용 버튼으로 저장"하는 것입니다.

커넥터의 권한 방식

비밀번호를 넘기는 게 아닙니다. "이 앱이 내 계정 일부를 쓰도록 허락"하는 방식(OAuth)입니다. 집 열쇠를 주는 게 아니라 "이 방까지만 들어와도 됩니다"라고 허락하는 것입니다. 연결하면 AI는 내 권한을 그대로 물려받습니다. MCP는 커넥터가 따르는 공개 표준입니다.

참고

메일 커넥터는 보통 초안 작성까지만 지원하고 발송 기능은 없습니다. AI가 초안까지 만들고 최종 발송은 사람이 하게 막아둔 안전장치입니다.

1-7API · API 키 · 환경변수

API는 프로그램끼리 정해진 방식으로 주고받는 창구입니다. 식당의 주문서 양식과 같습니다. 정해진 양식대로 주문하면 주방이 그대로 만들어 돌려줍니다.

API 키는 그 창구를 쓸 때 나를 증명하는 긴 비밀번호입니다. 쓴 만큼 내 카드로 요금이 청구됩니다.

환경변수는 그 비밀 값을 코드 바깥에 숨겨두는 파일입니다.

API 키 보안 4원칙
  1. 채팅창·스크린샷·공개 저장소에 절대 노출 금지
  2. 코드에 직접 쓰지 말고 환경변수에만 보관
  3. 사용자 화면이 아니라 서버에서만 사용
  4. 노출되면 즉시 재발급. 안 그러면 남이 내 요금으로 씁니다

상황도구이유
아이디어·문서 초안·카피채팅빠르고 저렴. 결과를 복사해 씀
화면·랜딩페이지·제안서 디자인디자인 도구캔버스에서 반복 수정, 실제 파일로 내보내기
파일 생성·수정, 코드, 배포코드 도구내 폴더에서 직접 파일을 만들고 고침
웹사이트 테스트·데이터 수집브라우저 도구브라우저를 사람처럼 조작
메일·문서·반복 업무업무 자동화 도구여러 단계 업무를 위임

업무 자동화 도구를 쓸 때 꼭 알 것

  • 작업은 내 컴퓨터가 아니라 격리된 가상 환경에서 돕니다.
  • 내가 허가한 폴더만 접근합니다. 다만 그 안에서는 읽기·쓰기·삭제까지 가능합니다.
  • 민감 자료 폴더를 통째로 허가하지 말고, 전용 작업 폴더를 만들어 그것만 허가하고 백업해 두세요.
  • 재료 폴더 / 결과물 폴더로 나누면 무엇이 원본이고 무엇이 결과인지 한눈에 정리됩니다.

예약 작업 — 한 번 시킨 일을 정해진 주기에 자동 반복하게 할 수 있습니다. 단, 컴퓨터가 켜져 있고 앱이 열려 있어야 돌고, 실행할 때마다 사용량을 씁니다.

PART 5

지켜야 할 것

보안

  • API 키·비밀번호·고객 개인정보는 채팅창에 붙여넣지 않습니다.
  • 공개 저장소에 올리지 않습니다.
  • 노출되면 즉시 재발급합니다.

검수

  • AI 결과물은 초안입니다. 사람이 확인하고 내보냅니다.
  • 수치·법률·계약 정보는 반드시 원본을 대조합니다.
  • 발송·게시처럼 되돌리기 어려운 행동은 사람이 마지막 버튼을 누릅니다.

비용

  • 사용량은 계정 전체로 합산됩니다.
  • 긴 대화가 가장 비쌉니다. 주제가 바뀌면 새 대화를 엽니다.
  • 쉬운 일에 최상위 모델과 최대 노력도를 쓸 이유가 없습니다.
